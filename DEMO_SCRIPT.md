# Emberline demo script

Target runtime: 80-100 seconds. The current final render is approximately 80 seconds.

## 0:00–0:20 — The problem

“Humanitarian funding needs accountability, but publishing raw evidence can expose beneficiaries and operational details. Emberline lets capital move only when independent reviewers verify a specific private evidence commitment.”

Show the project overview, funded capital, milestone ledger, and current locked/released amounts.

## 0:20–0:45 — Private evidence commitment

Connect as the implementer. Open a pending milestone and select a prepared evidence package.

“The file is hashed entirely in the browser. Emberline receives only this SHA-256 commitment and label; the private file is never uploaded.”

Submit the commitment and show the new immutable revision.

## 0:45–1:20 — Independent review and dispute

Connect as an assigned reviewer and flag the first revision.

“A single rejection freezes the gate. The implementer cannot erase this decision.”

Reconnect as the implementer, submit a corrected evidence revision, and point out that the prior revision remains in history.

## 1:20–1:55 — Attestcoin proof and quorum

Show the linked live testnet sample and the Creditcoin explorer transactions that registered each reviewer proof. Do not describe the synthetic guided sandbox records as on-chain transactions.

“Attestcoin binds each verified decision to the reviewer, project, milestone, revision, evidence commitment, and approval result. The escrow rejects mismatched, expired, revoked, or replayed proofs.”

Record the final approvals and show quorum becoming satisfied.

## 1:55–2:15 — Release

Trigger the milestone release and show the recipient balance or transaction in the Creditcoin explorer.

“Only the next sequential milestone can release, and only after the exact review policy is satisfied.”

## 2:15–2:30 — Audit and close

Show the audit status and recent events.

“Emberline does not claim a blockchain proves physical reality. It proves that an accountable, evidence-bound approval process controlled the capital. Every verified milestone moves aid forward.”

## Recording checklist

- preload owner, implementer, and reviewer sessions without exposing tokens
- use non-sensitive synthetic evidence files
- keep the Creditcoin explorer tabs ready
- zoom the browser so commitments and quorum are readable
- distinguish the session-scoped application sandbox from the separate live Attestcoin testnet sample
- record one clean uninterrupted take, then add captions
